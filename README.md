Download the latest pre-built, encrypted, and signed APK from the GitHub Releases tab:

If cloning or downloading from the repository source:

Extract the split parts using `7z`:
```bash
# On Linux / Termux:
7z x apk-split/GhostPin_3.30-encrypted.7z.001

# On Windows:
# Right-click GhostPin_3.30-encrypted.7z.001 -> 7-Zip -> Extract Here
```
